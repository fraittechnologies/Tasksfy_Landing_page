## ⚙️ Installation & Usage

### 🧩 Option 1 — Run Directly in Browser
1. Clone or download this repository:

   git clone https://github.com/fraittechnologies/Tasksfy_Landing_page.git


2. Open the folder on your computer.

3. Double-click **index.html** to open it in your browser.

### 💻 Option 2 — Run in Visual Studio Code

1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension (if not already installed).
3. Right-click `index.html` → choose **“Open with Live Server”**.
4. The page will open automatically in your default browser.
